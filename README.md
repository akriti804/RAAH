# RAAH

## Help, when you need it.

RAAH is a roadside and emergency assistance platform designed to help users quickly find relevant assistance during vehicle breakdowns, medical emergencies, and other urgent situations.

## Vision

To make emergency and roadside assistance easier to discover, request, and manage from one platform.

## Planned Technology Stack

- Frontend: React + Vite + Tailwind CSS
- Backend: Java + Spring Boot
- Database: MySQL
- API: REST API
- Authentication: JWT + BCrypt
- Version Control: Git + GitHub
